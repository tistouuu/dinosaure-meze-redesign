# Musée-Parc des Dinosaures — refonte

Refonte graphique non officielle du site [dinosaure.eu](https://www.dinosaure.eu/) (Musée-Parc des Dinosaures, Mèze, Hérault). Contenu, informations pratiques et photos repris du site d'origine.

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec n'importe quel serveur statique. Publié en ligne via GitHub Pages : https://tistouuu.github.io/dinosaure-meze-redesign/

**Contenu média :**
- `img/` — 19 photos reprises du site officiel (reconstitutions, fossiles, œufs, fouilles)
- Les deux vidéos de la page d'accueil (« La chasse aux œufs de dinosaures » et le reportage France 3) sont lues directement depuis le serveur de dinosaure.eu (`<video><source src="https://www.dinosaure.eu/...">`) — aucun fichier vidéo n'est copié dans ce repo. Avantage : pas de limite de taille Git à gérer. Inconvénient : si le musée change l'URL ou retire le fichier, la lecture casse ici aussi.

**Important :** le musée interdit explicitement tout usage commercial et toute diffusion sur le web de prises de vue du site sans autorisation écrite. Ce repo est public et les photos/la vidéo y sont diffusées à la demande du propriétaire de ce repo, en connaissance de cette restriction — à garder en tête en cas de doute sur la conformité.
