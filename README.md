# Musée-Parc des Dinosaures — refonte

Refonte graphique non officielle du site [dinosaure.eu](https://www.dinosaure.eu/) (Musée-Parc des Dinosaures, Mèze, Hérault). Contenu, informations pratiques et photos repris du site d'origine.

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec n'importe quel serveur statique.

**Important :** le musée interdit explicitement toute diffusion sur le web de prises de vue du site sans autorisation écrite. Ce repo est privé et doit le rester si les photos (`img/`) y restent incluses — ne pas publier via GitHub Pages ni rendre public sans l'accord du musée ou avoir retiré les photos.
